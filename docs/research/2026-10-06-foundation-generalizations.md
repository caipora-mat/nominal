## Adopted in the authorized freshness extension

Pitts' relation between supported elements of possibly different carriers is
`Fresh A x y := Disjoint (support A x) (support A y)`; see *Nominal Sets*
(CUP 2013), §3.1, equation (3.1), p. 49. The user explicitly authorized this
extension after reviewing that definition. The existing atom helper is now a
specialization, and `hx.FreshWith hy` supports individual elements without
whole-carrier nominality. No extra action, nominality instance, notation or
tactic is introduced.

The canonical/freshness investigation identified three useful general laws,
now incorporated in [Freshness.lean](../../Package/Foundations/Freshness.lean):

1. **Disjoint sufficient bounds characterize freshness**, rather than merely
   imply it:
   `hx.FreshWith hy ↔ ∃ S T, Supports S x ∧ Supports T y ∧ Disjoint S T`.
   The least supports witness the forward implication; minimality and
   `Disjoint.mono` prove the reverse. No decidable equality or nominality of
   either entire carrier is required.
2. **Finite atom sets form freshness contexts on either side**:
   `Fresh A S x ↔ ∀ a ∈ S, Fresh A a x`, and the symmetric variant.
   The elementwise variants use only a certificate for x. These reuse
   `support_finset` and `Finset.disjoint_left/right`. Equality and Pointwise
   are needed only because S is an acted-on Finset; disjointness of explicit
   finite bounds itself needs no equality parameter.
3. **Ordinary equivariant maps preserve freshness in either argument**.
   For example, `hx.FreshWith hy → hx.FreshWith (hy.map hf)` follows from
   `hy.support_map_subset hf` and `Disjoint.mono_right`. The implication is
   generally strict: an equivariant constant into discrete data can erase
   support. No supported-function object or function-space action is needed.

The general relation also supplies symmetry, self-freshness iff empty support,
product decomposition on both sides and simultaneous/inverse transport.
The existing atom theorem calls remain valid. Fully explicit `@Fresh` calls
now include both carriers, actions and nominality certificates; this is the
intentional interface generalization. The old evidence form `hx.Fresh a`
is retained and derived from the atom specialization.

### Equivariant reflection and nominality transfer

For an ordinary equivariant injection f,

```text
Supports S (f x) ↔ Supports S x
FinitelySupported A (f x) ↔ FinitelySupported A x
(hx.map hf).support = hx.support                 -- Infinite A
```

The first two require neither infinitude nor decidable equality; none needs
whole-carrier nominality. Reflection cancels f after using equivariance.
At carrier level, an equivariant injection pulls nominality back from its
codomain, while an equivariant surjection sends domain nominality to the
codomain. These are intended as explicit constructor theorems for selected
actions, not unrestricted typeclass-search rules. The surjective direction is
now implemented as such in F04d; the injective direction remains research.
Preimages stay inside proof fields.

The support-reflection parent in the probe uses only `SMul G A`, `SMul G X`,
`SMul G Y`, arbitrary `S : Set A` and a commuting-map equation. Mathlib's
`MulAction.Supports` supplies the definition. Surjective object maps still
give only support inclusion; predicate pullback reflection is a different
later theorem.

### Transport and local intersection

For `[Group G] [MulAction G A] [MulAction G X]`, the probe proves

```text
MulAction.Supports G (g • S) (g • x) ↔ MulAction.Supports G S x
```

for arbitrary `S : Set A`. The proof uses `g⁻¹ * h * g`, not a commutation
assumption. Pinned Mathlib's `MulAction.Supports.smul` has a different
two-scalar commuting-action contract. Keep its predicate and standard Set
action; add only the missing same-group lemma if adopted.

For finite bounds, `S.map π.toEquiv.toEmbedding` expresses transport without
`DecidableEq A`. `Finset.coe_map` and `map_eq_image` connect it to the existing
scoped image notation. The corresponding least-support equation is checked
under `Infinite A`, again without a public equality premise. The readable
`π • S` equations can remain adapters with their existing equality/scope policy.

For the permutation support intersection theorem, the checked stronger premise
is merely `∃ c, c ∉ S ∧ c ∉ T`, for arbitrary sets S,T. Swaps whose endpoints
both avoid one bound are handled directly; the cross cases use c, which is
automatically distinct from endpoints lying in the union. Classical equality
stays inside the proof. The Finset/Infinite specialization uses
`Finset.exists_notMem (S ∪ T)`.

**Essential limit:** arbitrary supporting sets need not contain least finite
support. The checked counterexample proves that `{a}ᶜ` supports a but omits a,
which belongs to its least finite support over infinite atoms. Thus the
finite `supports_iff_support_subset` cannot be generalized to arbitrary sets
without an additional hypothesis. Retain the Bool intersection obstruction too.

### Actions, fixers and atom equivalences

Mathlib's `MulActionHom` already works with scalar operations and independent
universes. All five Package equivariance combinators have checked `SMul`-only
proofs. The current equivariance proof converts to `X →[Perm A] Y` by
`⟨f,hf⟩`, and `map_smul` gives the converse; application is definitionally
unchanged. No competing equivariant-map structure is warranted.

Using Mathlib's `fixingSubgroup`, the checked algebraic strengthening is

```text
fixingSubgroup (Perm A) S =
  Subgroup.closure {π | ∃ a b, a ∉ S ∧ b ∉ S ∧ π = Perm.swap a b}
```

Its containment in any subgroup H is equivalent to H containing every
outside swap. Specializing H to an element's stabilizer recovers the current
action criterion. This requires decidable equality for swaps, but no infinitude
or finiteness of S. Endpoint-controlled factorization is reused unchanged.

The atom-equivalence probe restricts `Equiv.permCongrHom` using Mathlib's
`MulEquiv.subgroupMap`/`subgroupCongr`, yielding `Perm A ≃* Perm B` from
`e : A ≃ B`, across independent universes. It proves application, moved-set
image and swap transport, then recovers the present conjugation law.
Only the swap equation needs equality decisions. This is a representation
invariance adapter, not a multiple-atom-sort redesign.

### Directedness and leastness

The checked extraction uses
`DirectedOn (fun S T : Finset A => T ⊆ S) {S | Supports S x}` and a finite
support certificate to produce the unique least finite support. It needs no
infinitude or equality assumption. Mathlib's
`DirectedOn.minimal_iff_isLeast` and the existing well-founded Finset order
already supply the general order argument. Intersection closure gives the
needed directedness in the current infinite-atom theorem. A helper existence
result is additive; changing `hx.support` to require directedness would be a
separate interface decision and is not proposed as a prerequisite for F04d.
